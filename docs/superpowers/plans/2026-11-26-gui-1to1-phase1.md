# GUI 1:1 — Phase 1 (reference, layout module, fidelity harness, gap inventory) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build everything the per-window ports need: an extracted reference of every upstream
WinForms window, a WinForms-style layout module for egui that records what it draws, a
fidelity comparer that checks a drawn window against its reference, a deviations log, and a
gap inventory of missing logic.

**Architecture:** A test-side parser turns the pinned upstream `*.Designer.cs` (+ `.resx`)
into committed JSON under `docs/gui-reference/`. The library gets `ui::forms`: pure geometry
(Dock, SplitContainer, Anchor, Designer scale) plus container/widget helpers that append to a
per-frame trace when tracing is on. A test-side comparer matches trace against reference and
an allowlist whose entries must cite a deviation in `docs/gui-deviations.md`. No window is
ported in this phase; per-window ports get their own plans after the gap inventory.

**Tech Stack:** Rust, egui/eframe 0.37, egui_kittest 0.37 (no new features), serde/serde_json.

**Spec:** `docs/superpowers/specs/2026-11-26-gui-1to1-design.md`

## Global Constraints

- No new crates, no new dependency edges, no new features: `Cargo.lock` unchanged; never `cargo update`.
- `tests/golden/*.json` and `upstream_commit` unchanged.
- Upstream pinned at `91b02cb7f4210f3cf1e2cb7c3666ce29b65e69c5`; source via `tools/fetch-upstream.sh` into `target/upstream/AirScout`.
- Reference files are written only by the generator; hand edits forbidden.
- `ReflectionDlg` is excluded (dead upstream).
- Designer `Font` ignored; Designer pixels (96 dpi) map 1:1 to egui points (`DESIGNER_SCALE = 1.0`).
- Text comparison: strip single `&` mnemonics (`&&` → `&`), `\r\n` → `\n`, trim ends.
- Controls with `Visible = false` in the Designer are excluded from checks.
- Rust-only extras only after the original controls of a container, and only if allowlisted with a deviation id.
- Synthetic test values only (TE1ST, JO50AA, 3C0001, localhost); never copy station data, calls or LAN addresses from Designer defaults into code or fixtures.
- Cargo: prefix `CARGO_INCREMENTAL=0 CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_TEST_DEBUG=0`, use `--locked`.
- Gates per task: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets --locked -- -D warnings`, `cargo test -p airscout --locked`. Signed commits (`git commit -S`).
- Snapshot images are **not** part of this phase: egui_kittest snapshots need its `snapshot`/`wgpu` features, which change `Cargo.lock` (Ruling, see ledger; owner to decide).

## Review Focus

1. Multi-line Designer string concatenation (`"a" +\n "b"`) and C# escapes (`\r\n`, `\"`, `\\`, `@"..."`) must yield the exact visible text — test in Task 1.
2. `resources.GetString("x.Text")` texts (19 uses, e.g. `FirstRunWizard`, `DeleteSingleStationDlg`) must resolve from the `.resx`, with XML entities decoded — test in Task 1.
3. WinForms docks children in reverse `Controls.Add` order; getting this backwards swaps Fill and Top panels in every window — test in Task 3.
4. Tracing off must cost nothing and record nothing (production frames) — test in Task 4.
5. An allowlist entry citing a deviation id missing from `docs/gui-deviations.md` must fail, not pass — test in Task 5.

  ```rust
      pub client_size: Option<[i32; 2]>, pub controls: Vec<Control>, pub unparsed: Vec<String> }
  pub struct Control { pub name: String, pub kind: String /* "Label", "GroupBox", "ColumnHeader", custom type name … */,
      pub parent: String /* "$this", a control name, or "sc_Main.Panel1" */, pub index: usize /* order in parent's Controls/Items/Columns */,
      pub text: Option<String>, pub location: Option<[i32; 2]>, pub size: Option<[i32; 2]>,

  ```
- Produces: `gui_ref::designer::parse(window: &str, src: &str, resx: &dyn Fn(&str) -> Option<String>) -> model::Window`
- Produces: `gui_ref::resx::lookup(resx_xml: &str, key: &str) -> Option<String>`
- Kind comes from `this.x = new A.B.Type(...)`: last path segment (`System.Windows.Forms.Label` → `Label`, `GMap.NET.WindowsForms.GMapControl` → `GMapControl`).
- Parent rules: `this.p.Controls.Add(this.c)` → parent `p`; `this.Controls.Add(this.c)` → `$this`; `this.sc.Panel1.Controls.Add(this.c)` → `sc.Panel1`; `this.p.Items.AddRange(new ...ToolStripItem[] { this.a, this.b })` and `Columns.AddRange` → children `a`, `b` of `p` with index by position; `Items.AddRange(new object[] { "x", "y" })` → `items` of `p`. Form-level `this.Text`/`this.ClientSize` → `title`/`client_size`.
- `unparsed`: statements starting with `this.` that assign `Text|Location|Size|Dock|Anchor|Visible|Enabled|TabIndex|SplitterDistance|Orientation` with a value the parser cannot read, and `Controls.Add`/`AddRange` forms it does not know. Every other property assignment is ignored silently.

### Task 3: Layout geometry

**Files:**
- Create: `crates/airscout/src/ui/forms/{mod.rs,geometry.rs}`; Modify: `crates/airscout/src/ui/mod.rs` (`pub mod forms;`)
- Test: `crates/airscout/tests/gui_forms.rs`

**Interfaces:**
- Produces (`airscout::ui::forms::geometry`):
  ```rust
  pub const DESIGNER_SCALE: f32 = 1.0;
  pub const SPLITTER_WIDTH: f32 = 4.0;
  #[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum Dock { None, Top, Bottom, Left, Right, Fill }
  #[derive(Clone, Copy, Debug, PartialEq, Eq)] pub struct Anchor { pub top: bool, pub bottom: bool, pub left: bool, pub right: bool }
  impl Default for Anchor /* top + left */;
  #[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum Orientation { Horizontal /* panels stacked */, Vertical /* side by side */ }
  pub fn designer_rect(parent: Rect, location: [i32; 2], size: [i32; 2]) -> Rect;
  pub fn dock_layout(area: Rect, children: &[(Dock, Vec2)]) -> Vec<Rect>; // children in Controls.Add order, Vec2 = designer size
  pub fn split(area: Rect, orientation: Orientation, distance: f32) -> (Rect, Rect);
  pub fn anchored(designer_parent: Vec2, parent: Rect, location: [i32; 2], size: [i32; 2], anchor: Anchor) -> Rect;
  ```
- `dock_layout`: process children from the **last** to the first (WinForms reverse z-order); Top/Bottom take their height across the remaining width, Left/Right take their width across the remaining height, Fill takes the remainder; `Dock::None` children get `Rect::NOTHING` (caller places them with `designer_rect`/`anchored`). Result is in input order.
- `split`: Vertical → left width `distance`, right starts at `distance + SPLITTER_WIDTH`; Horizontal analogous on y. Distance clamped to `[0, extent − SPLITTER_WIDTH]`.
- `anchored`: per axis — both edges anchored: keep both margins (stretch); only far edge: keep far margin; only near edge or none: keep near position (WinForms centres with none; treat none as near, Ruling).

### Task 5: Fidelity comparer, allowlist, deviations log

**Files:**
- Create: `crates/airscout/tests/gui_ref/fidelity.rs`, `docs/gui-deviations.md`
- Test: `crates/airscout/tests/gui_fidelity.rs`

**Interfaces:**
- Consumes: Task 1 model, Task 2 `load`, Task 4 `trace::Entry`.
- Allowlist file: `docs/gui-reference/<Window>.allow.json`, optional, array of
  `{ "name": String /* control name or Rust-only name */, "what": "missing"|"extra"|"text"|"moved"|"geometry", "reason": String, "deviation": String /* e.g. "D-003" */ }`.
- Deviations log: `docs/gui-deviations.md`, one `## D-NNN <title>` heading per deviation with lines `Window:`, `Differs:`, `Why:`, `Approved: YYYY-MM-DD`.
- Produces:
  ```rust
  pub enum Mismatch { Missing { name: String, text: String }, WrongText { name: String, expected: String, got: String },
      WrongContainer { name: String, expected: Vec<String>, got: Vec<String> }, WrongOrder { container: String, expected: Vec<String>, got: Vec<String> },
      Extra { name: String, container: String }, WrongDockSide { name: String, dock: String },
      WrongSplit { name: String, expected: f32, got: f32 }, UnknownDeviation { name: String, deviation: String } }
  pub fn compare(reference: &Window, trace: &[Entry], allow: &[Allow], deviations: &str) -> Vec<Mismatch>;
  pub fn assert_window(window: &str, trace: &[Entry]); // loads reference, allowlist, deviations; panics listing all mismatches
  ```
- Rules: checked controls are those with non-empty `text`, `visible == true`, of kind Label, LinkLabel, Button, CheckBox, RadioButton, GroupBox, TabPage, ColumnHeader, ToolStripStatusLabel. Expected path = ancestor names from the reference (excluding `$this`; `sc.Panel1` counts as its own element). Order per container: sort by `(round(y / 10), x)` on both sides (Designer location vs trace rect min) and compare name sequences; allowlisted extras must come after all original names. Dock: a docked reference control's trace rect must touch that side of its parent container's trace rect within 2 pt. Split: `SplitContainer` ratio `distance / extent` within ±0.05 of the trace ratio (trace records the container's two panels as `<name>.Panel1/2`). Every allowlist entry's `deviation` must appear as a `## D-NNN` heading, else `UnknownDeviation`.
