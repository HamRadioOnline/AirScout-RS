# Stage 6 area 4 implementation plan

**Goal** — Implement the 27 approved fixes in GUI and integrations, verify the 33 keep decisions, and record evidence for later C# pull requests.

**Architecture** — Enforce each integration at its wire boundary: a Win-Test datagram, a DDE poke, a CAT poll and a GS-232A rotator query. Commit `fix(as-wintest): validate datagrams and resolve the requested band`.
2. **Track outputs and rotator (#203, #206, #236, #237, #239, airscout).** Reset a group's error counter on a successful step, count serial timeouts and I/O errors once toward switch-off, write `azel.dat` atomically through a same-directory temp file and rename, and round-then-wrap/clamp the GS-232A set command. Verify an occasional failure does not accumulate toward switch-off, the serial output switches off at the 11th error not the 6th, a reader never observes a torn line, and 359.6 → `000`, −5 → `000` with non-finite inputs clamped to 0. Commit `fix(airscout): bound track-output errors and rotator positions`.
3. **Web JSON scrubbing (#257, #277, airscout).** Strip userinfo and drop the query string except the page's `%MINLAT%`…`%MAXDISTKM%` placeholders from the public `/planefeedsettings.json` VRS URLs, and do the same for `KST_Websocket` in `/settings.json`, warning against path-embedded tokens.
