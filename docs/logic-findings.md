# Logic findings (original AirScout code)

Suspected defects found while porting. **Stage 1 reproduces all of them on purpose** so the
golden tests prove a faithful port. Stage 6 fixes them one by one, each with a failing test and
a recorded golden-test delta.

Upstream: dl2alf/AirScout @ `fbadef0f` (V1.4.5.1). The base was `91b02cb7f4210f3cf1e2cb7c3666ce29b65e69c5` up to and including #338; the cites into `OpenSky.cs`, `ADSBOne.cs` and `PublicBinCraft.cs` were re-checked at `fbadef0f`.
