AirScout-RS web page: components and licences
=============================================

The web page that AirScout-RS serves is a subset of the AirScout web
page (AirScout/wwwroot). Each file below is copied byte for byte from
AirScout at commit 91b02cb. The only change is line 563 of
resources/js/airscout.core.js: the page asks its own origin for data.

Each entry names a component, its version, its licence, the licence
text in this directory, the upstream source and the embedded files.
All licences are compatible with the GNU GPL version 3.
